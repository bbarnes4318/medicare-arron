# TrustedForm Certificate Retention Setup

## Overview

We have implemented logic to automatically **retain** TrustedForm certificates when leads are submitted. This ensures that you have a permanent record of the TrustedForm certificate for compliance and verification purposes.

## How It Works

1.  **Capture**: When a form is submitted via the agent portal, the system uses a headless browser to fill the form on `lowinsurancecost.com`. During this process, it captures the `xxTrustedFormCertUrl` generated by the page.
2.  **Retain**: Immediately after capturing the certificate URL, the system makes a server-side API call to TrustedForm to **retain** the certificate.
3.  **Store**: The certificate URL is stored in your local database (`leads.db`) and Google Sheets.

## Verification

To verify that certificates are being retained:

1.  Submit a form through the agent portal.
2.  Check the server logs for the message: `✅ TrustedForm Certificate Retained Successfully!`.
3.  You can also check your TrustedForm account dashboard to see the retained certificates.
