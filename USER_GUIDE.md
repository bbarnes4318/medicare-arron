# Medicare Form Portal - User Guide

## 1. Access the Portal

Open your web browser and navigate to the application URL provided by your administrator.
_(Example: https://medicare-form-do-user-xxxx.ondigitalocean.app)_

## 2. Login

Enter your assigned credentials on the login screen.

**Agent Login:**

- **Username:** `agent1` (or your assigned agent number, e.g., `agent25`)
- **Password:** `password123`

**Admin Login:**

- **Username:** `admin`
- **Password:** `admin123`

## 3. Submit a Form

1. Click on **"Submit Form"** from the dashboard.
2. Fill in the required fields:
   - State
   - Zip Code
   - First Name
   - Last Name
   - Phone Number
3. Check the **Disclosure** box to agree to the terms.
4. Click **"Submit Form"**.
   - The system will automatically use a residential proxy to submit the data securely.
   - You will see a success message confirming the submission.

## 4. View Leads

1. Click on **"View Leads"** from the dashboard.
2. You will see a table of all captured leads, including:
   - Timestamp
   - Name
   - Phone
   - State/Zip
   - TrustedForm Certificate link
